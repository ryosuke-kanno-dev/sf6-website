# Webサイト本番環境構築・本番移行計画書

本ドキュメントは、ローカル環境（XAMPP）で完成させた Webサイト（PHP + MariaDB）を本番環境へ公開し、2台のPCでの開発効率化および動画配信を最適化するための構成・ロードマップをまとめたものです。

---

## 1. 全体アーキテクチャ概要

個人開発において「完全無料〜極めて低コスト」かつ「2台のPCでの開発同期の手間をゼロにする」プロ仕様の構成を採用します。

[ ユーザー (ブラウザ) ]
│
├── ① Webサーバー (PHP実行)   : Render / Railway
├── ② データベース (データ管理)  : Supabase (Cloud PostgreSQL/MariaDB)
└── ③ 動画・メディアストレージ : Cloudflare R2 または YouTube

---

## 2. 各インフラ構成と選定理由

### ① Webサーバー（ホスティング）
* **採用サービス**: **Render**（または Railway）
* **特徴・役割**:
  * GitHub リポジトリと連携し、`git push` を実行すると自動で本番環境にデプロイ（更新）される。
  * PHP 環境を手軽かつ安価（基本無料枠あり）で運用可能。

### ② データベース（クラウドDB）
* **採用サービス**: **Supabase**（または Aiven）
* **特徴・役割**:
  * データベースをクラウド化することで、ノートPC・デスクトップPC・本番サーバーのすべてから**「単一の最新DB」**へ直接接続。
  * `.sql` ファイルの手動エクスポート／インポート作業が完全に不要化。

### ③ 動画配信（メディアストレージ）
動画をデータベースやGitリポジトリへ直接入れることは「アンチパターン」として避け、用途に応じて以下の2パターンで管理・参照する。

* **パターンA：YouTube 埋め込み（`<iframe>`）**
  * **対象**: 解説動画、試合のプレイ動画などの長尺コンテンツ。
  * **メリット**: 完全無料。自動画質調整・高速配信をすべてYouTubeに委任可能。
* **パターンB：Cloudflare R2（`<video>` タグ参照）**
  * **対象**: 背景動画、UI用ループ動画、PVなどの短い動画。
  * **メリット**: **データ転送料金が完全無料**（10GBまで保管無料）。プレイヤーのロゴを出さずデザインに組み込み可能。

## 3. 本番公開までのロードマップ

ページの見た目・機能がローカル環境（XAMPP）で完成した後の手順です。

### フェーズ 1：動画ファイルのクラウド移行
1. 本番用動画を YouTube（限定公開）または Cloudflare R2 へアップロードする。
2. データベースや PHP コード内の動画参照パスを、サンプルURLから取得した本番URL（`https://...`）に書き換える。

### フェーズ 2：クラウドデータベース（Supabase）の導入
1. Supabase に無料アカウントを作成し、新しいデータベースプロジェクトを作成する。
2. ローカルの MariaDB から書き出したテーブル構造・データを Supabase に初期移行する。
3. PHP の DB 接続ファイル（`db_connect.php`）の接続先情報を Supabase のホスト名・パスワードに変更する。

### フェーズ 3：Webサイトの本番公開（Render デプロイ）
1. Render にアカウントを作成し、GitHub の `SF6_WebSite` リポジトリを接続する。
2. 環境変数（DB接続情報など）を設定し、初回ビルド・デプロイを実行する。
3. 発行された URL（`https://xxx.onrender.com` など）でブラウザからアクセスし、動作確認を行う。

---

## 4. 今後の開発における基本原則

* **動画の管理**: ローカル開発中はサンプル動画URL（または極小サイズのダミー動画）を使用し、大容量動画は Git の追跡対象に含めない（`.gitignore` で除外）。
* **コードの管理**: 開発中のコード修正・パス調整は **Google Antigravity IDE** のエージェント機能を活用して自律修復・自動化する。
