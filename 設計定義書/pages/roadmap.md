# 上達法 (roadmap.php) 仕様設計書

## 1. ページの目的 (Purpose)
ユーザーの現在の実力（ランク）に合わせて、次に習得すべき考え方や行動、具体的な練習方法（ロードマップ）を提示します。「今の自分が何をすべきか分からない」という迷いをなくし、`training.php` や `combo.php` へと自然に誘導します。

## 2. ターゲットユーザー (Target User)
- ランクマッチで勝てずに壁を感じている全プレイヤー
- 自分の現在のランクにおいて、過不足のない（適正な）目標を知りたいプレイヤー

## 3. データソースと管理方法 (Data Source)
- **解説テキスト**: Markdownファイル (`data/roadmap/` 以下のファイル等) または `roadmap.json`
- Markdownで執筆された長文の解説を、Parsedown（`lib/Parsedown.php`）を使用してHTMLにパースして表示します。

## 4. コンポーネント構成 (Component Structure)
- `sections/roadmap/nav.php`: ランク帯（ルーキー、ブロンズ、シルバー、ゴールド、プラチナ、ダイヤ、マスター）を選ぶためのサイド・トップナビゲーション
- `sections/roadmap/content.php`: 選択されたランク帯の目標、考え方、おすすめの練習メニューを出力するメインコンテンツ

## 5. UI / 機能の振る舞い (UI / Functional Behavior)
- **ランク別表示切り替え**: URLパラメータ（例: `?rank=gold`）またはJSのタブ切り替えによって、該当するランクのロードマップだけを表示する。
- **具体的なアクションへの誘導**: ロードマップ内で「対空の練習をしよう」と解説した場合、そのすぐ下に `training.php?menu=taiku` へのリンク（アクションボタン）を配置し、記事を読んで終わらせず実践へ繋げる。
- **プログレス感の演出**: ランクのアイコン画像（`img/rank/`）を活用し、昇格していくモチベーションを高めるデザイン。

## 6. 運用・保守の注意点 (Maintenance)
- ゲームバランスの調整（シーズン変更など）によって定石が変わった場合は、Markdown記事の内容を修正する。
- 記事のパースには `lib/Parsedown.php` の `text()` メソッドを使用し、XSS等のリスクを減らすため `setSafeMode(true)` の設定を維持すること。
