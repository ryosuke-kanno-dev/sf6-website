# キャラ対策 (matchup.php) 仕様設計書

## 1. ページの目的 (Purpose)
対戦相手のキャラクターごとに、弱点、確定反撃（確反）、連携の抜け方、立ち回りのセオリーをまとめます。「この技をガードしたらどうすればいいか？」「どうやって近づけばいいか？」という実戦の悩みを即座に解決する辞書として機能します。

## 2. ターゲットユーザー (Target User)
- ランクマッチ等で特定のキャラクターに勝てず（わからん殺しされ）、対策を調べに来たプレイヤー

## 3. データソースと管理方法 (Data Source)
- **DB (MySQL)**: `sf6` データベース
  - `characters` テーブル: キャラクター情報
  - `frame` テーブル: キャラごとの全技のフレームデータ（発生、ガード硬直など）
  - `matchup_guides` テーブル: キャラごとの具体的な対策文章や画像URL
- **共通ロジック**: `includes/functions/db_helpers.php` を利用したキャラ情報取得。

## 4. コンポーネント構成 (Component Structure)
- `sections/_shared/char_select.php`: （`combo.php`と共通）相手キャラクター選択グリッド
- `sections/matchup/char_detail.php`: キャラ対策の詳細を表示するメインビュー
  - この中に「立ち回り」「警戒すべき技」「確定反撃リスト」などの小セクションが含まれます。

## 5. UI / 機能の振る舞い (UI / Functional Behavior)
- **URLパラメーターによるルーティング**:
  - `?char=` なしの場合: `_shared/char_select.php` を表示
  - `?char={slug}` の場合: そのキャラに対する対策（`char_detail.php`）を表示。
- **アコーディオン（折りたたみ）表示**: 対策情報（特に技ごとの詳細解説）は長くなりがちなため、セクションごとにアコーディオンで折りたたみ可能にし（`.p-matchup__acc-trigger`）、見たい情報だけを探しやすくする。
- **自動確定反撃算出（将来拡張）**: `frame` テーブルの `ガード硬直` が -4F 以下のものを自動で引っ張り出し、「確反リスト」として表示するロジックを実装可能。

## 6. 運用・保守の注意点 (Maintenance)
- ゲームのバランス調整アップデート時に、フレームデータの変更に合わせて `frame` テーブルを最優先で更新する。
- 対策の解説文はメタ的な要素（例: 「今はこの行動が強い」）を含むため、定期的にプロシーンやトレンドを反映して `matchup_guides` テーブルをリライトする必要がある。
