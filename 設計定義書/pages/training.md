# トレモ実践 (training.php) 仕様設計書

## 1. ページの目的 (Purpose)
知識を得た後に「実際どうやってトレーニングモードで練習すればいいのか」を具体的に提示します。ただ文字で説明するだけでなく、ゲーム内の「レコード設定」の手順と、成功例の「動画」をセットで提供し、効率的な反復練習をサポートします。

## 2. ターゲットユーザー (Target User)
- 頭では分かっているが、実戦で咄嗟に手が出ないプレイヤー
- 新しいコンボや対空、起き攻めの精度を上げたいプレイヤー

## 3. データソースと管理方法 (Data Source)
- **データ管理**: `data/training_menus.json` 
- jsonファイルには以下の要素を含むオブジェクトの配列としてデータを格納します：
  - `id`: 練習メニューの一意のID
  - `title`: 練習のタイトル（例: 「ジャンプ攻撃に対する対空練習」）
  - `difficulty`: 難易度（★の数など）
  - `category`: カテゴリ（対空、差し返し、起き攻め等）
  - `recordings`: 相手キャラにレコードさせる行動のリスト（スロット1、スロット2...）
  - `videoUrl`: お手本動画（ローカルのWebM/MP4、またはYouTube等の埋め込み用URL）
  - `instructions`: 練習のやり方・注意点

## 4. コンポーネント構成 (Component Structure)
- `sections/training/navigation.php`: サイドバー。難易度やカテゴリ（対空、差し返しなど）でメニューを絞り込むためのナビゲーション
- `sections/training/routine.php`: ルーティン一覧の表示
- `sections/training/menu.php`: 個別の練習メニューを表示するカード。動画プレイヤー、レコード設定表、解説テキストを内包する
- `sections/training/knowledge.php`: 基礎知識部分の表示

## 5. UI / 機能の振る舞い (UI / Functional Behavior)
- **タブ / 絞り込み機能**: `js/training.js` を用いて、選択したカテゴリの練習メニューだけを非同期またはCSS表示非表示で瞬時に切り替える。
- **動画の自動再生 / ループ**: 練習メニューを開いた際にお手本動画がループ再生（音声なし・ミュート推奨）され、視覚的に正解の動きがインプットされるようにする。
- **レコード設定のステップ表示**: 「ダミー設定 -> レコード -> 再生」という手順を視覚的にわかりやすいステップUIで表現する。

## 6. 運用・保守の注意点 (Maintenance)
- 動画を追加する際は `videos/trainings/` 配下に配置し、軽量化（1080p以下、数十秒程度）を徹底すること。
- メニューが増えすぎた場合は、`training_menus.json` をカテゴリ別にファイルを分割することも将来的に検討する。
