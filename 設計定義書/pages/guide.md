# スタートガイド (guide.php) 仕様設計書

## 1. ページの目的 (Purpose)
SF6を始めたばかり、あるいはこれから本腰を入れて取り組む初心者に向けて、ゲームを快適にプレイするための基礎知識（デバイス選び、操作タイプ、オプション設定、UI解説）をワンストップで提供すること。

## 2. ターゲットユーザー (Target User)
- SF6を購入したばかりの完全初心者
- 他の格闘ゲーム経験者で、SF6特有のシステムや設定（モダン操作等）を知りたい人

## 3. データソースと管理方法 (Data Source)
このページは主に静的な解説文章で構成されています。
文章やリストの大部分はPHPファイル内にハードコード、あるいは Markdown/JSON からの読み込みで管理します。現状は静的HTML主体の構成です。

## 4. コンポーネント構成 (Component Structure)
情報量が多いため、テーマごとにセクションを分割し、`sections/guide/` 以下のファイルとして管理しています。

- `sections/guide/overview.php`: 導入・ページ概要
- `sections/guide/devices.php`: デバイス紹介（パッド、アケコン、レバーレスの比較）
- `sections/guide/operation_types.php`: 操作タイプ解説（クラシック vs モダン）
- `sections/guide/getting_started.php`: アカウント連携、ゲーム開始までの手順
- `sections/guide/tutorials.php`: ゲーム内チュートリアルの受け方と重要ポイント
- `sections/guide/ui_guide.php`: 画面UIの見方（各種ゲージ、タイマー等）
- `sections/guide/settings.php`: おすすめのオプション設定、ボタンコンフィグ

## 5. UI / 機能の振る舞い (UI / Functional Behavior)
- **サイドバーナビゲーション**: 縦に長いページになるため、画面左（PC）または固定メニュー（モバイル）として、各セクションへのアンカーリンク（目次）を配置。
- **セクション区切り**: 各テーマが明確に区切られるように、`section-dark` と `section-darker` を交互に配置し、視覚的なメリハリをつける。
- **カードレイアウト**: 操作タイプの比較などは、表ではなくカードUIで表示し、スマホでの見やすさを優先する。

## 6. 運用・保守の注意点 (Maintenance)
- ゲームの大型アップデートでUIやシステム（新しい操作タイプなど）が追加された場合のみ更新する。更新頻度は低め。
- 各セクションのファイル名（スネークケース）は変更しないこと。変更した場合は `guide.php` 側の `include` パスも修正が必要。
