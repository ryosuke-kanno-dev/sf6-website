# 攻略トップ (index.php) 仕様設計書

## 1. ページの目的 (Purpose)
サイト全体の玄関口（フロントページ）として機能し、ユーザーが次にどの情報へアクセスすべきかを迷わず提示すること。また、最新のアップデートや新着コンテンツを告知する役割も持ちます。

## 2. ターゲットユーザー (Target User)
- サイトを初めて訪れた全ユーザー
- 日常的に更新情報をチェックしたいリピーター

## 3. データソースと管理方法 (Data Source)
- **静的情報 (`data/site_info.json`)**: 
  - ヒーローセクションのタイトル、サブタイトル、CTAのリンク先
  - クイックナビゲーションの項目
  - 「このサイトの特徴」セクションの文章
- **最新情報 (`data/updates.json`)**: 
  - ニュース、新着記事のピックアップ表示

## 4. コンポーネント構成 (Component Structure)
ルートの `index.php` はコントローラーおよび全体の骨格として機能し、各セクションは `sections/home/` 以下のファイルをインクルードします。

- `sections/home/hero.php`: ヒーローセクション（アイキャッチとメインのCTAボタン）
- `sections/home/quick_nav.php`: 目的別クイックナビゲーション（グリッド表示のカード群）
- `sections/home/features.php`: サイトの特徴・コンセプト説明
- `sections/home/updates.php`: 最新情報のリスト（データが存在する場合のみ表示）
- `sections/home/cta.php`: ページ最下部のCTA（ロードマップ等への最終誘導）

## 5. UI / 機能の振る舞い (UI / Functional Behavior)
- **ファーストビュー**: 画面に大きくサイトコンセプトを表示し、最も重要な導線（ランク診断や練習メニュー）へのボタンを目立たせる。
- **レスポンシブデザイン**: スマホ閲覧時はカードリスト（クイックナビ、特徴）が縦1列または2列になり、縦スクロールで自然に読み進められるように配置。
- **広告枠**: ヒーロー下、および特徴セクションと最新情報の間に広告スペースを設ける。

## 6. 運用・保守の注意点 (Maintenance)
- サイトのメイン導線が変わった場合は `site_info.json` の `quickNav` を更新する。
- お知らせを更新する場合は `updates.json` を編集する。画像やアセットは `img/` 配下に格納してリンクする。
