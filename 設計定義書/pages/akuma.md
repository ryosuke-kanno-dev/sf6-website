# 豪鬼特設ページ (akuma.php) 仕様設計書

## 1. ページの目的 (Purpose)
SF6における「豪鬼」というキャラクターを使いこなすために必要な情報を、すべて1ページに集約した特化型ページです。他ページ（コンボ集や対策ページ）の共通データを使いつつも、豪鬼専用の深い戦術やセットアップを重点的に解説します。

## 2. ターゲットユーザー (Target User)
- 豪鬼をメインキャラクターとして使用しているプレイヤー
- 豪鬼の強み・弱み、セットアップ（起き攻め・詐欺飛び）を深く理解したいプレイヤー

## 3. データソースと管理方法 (Data Source)
- **静的データ (PHP/Markdown)**: 「強みと弱み」「立ち回りの基本」「リーサル判断」などは静的なPHPセクション内に記述。
- **動的データ (MySQL)**: 
  - `characters` テーブル: `getCharacterBySlug($pdo, 'gouki')` を用いて豪鬼の基本情報を取得。
  - `frame` テーブル: 豪鬼のフレームデータをDBから読み込み。
- **共通ロジック**: コマンドの画像変換には `command_converter.php` を使用し、デザインを他ページと統一。

## 4. コンポーネント構成 (Component Structure)
このページは情報量が非常に多いため、完全にコンポーネント（セクション）分割して管理しています。

- `sections/akuma/hero.php`: ファーストビュー（豪鬼専用のダークで攻撃的なデザイン）
- `sections/akuma/page_nav.php`: ページ内の各セクションへ飛ぶためのアンカーナビゲーション
- `sections/akuma/strength.php`: 豪鬼の強み・弱みの解説
- `sections/akuma/tactics.php`: 立ち回りの基本と牽制技の振り方
- `sections/akuma/lethal.php`: リーサル判断（体力状況に応じたコンボルート選択）
- `sections/akuma/combo.php`: 豪鬼専用の実戦コンボ集
- `sections/akuma/okizeme.php`: 起き攻めと柔道（投げループ）の解説
- `sections/akuma/setup.php`: 詐欺飛びや持続当てなどの専用セットアップ
- `sections/akuma/matchup.php`: 豪鬼視点での主要キャラ対策
- `sections/akuma/framedata.php`: フレームデータ一覧（`matchup.php`のデザインを流用）

## 5. UI / 機能の振る舞い (UI / Functional Behavior)
- **専用テーマカラー**: 他の共通ページとは異なり、豪鬼を象徴するカラー（紫みのダークグレーと赤）を用いた専用CSS (`akuma.css`) を読み込む。
- **スティッキーナビゲーション**: ページが長いため、スクロールに追従するページ内ナビゲーション（`page_nav.php`）を配置し、読みたい項目にいつでもジャンプできるようにする。
- **コマンドアイコンの共通化**: コンボやセットアップの解説内に出てくるコマンドは、`combo.css` と同じ基盤を用いて直感的な画像アイコンで表示する。

## 6. 運用・保守の注意点 (Maintenance)
- `akuma.php` は専用の特別ページであるため、今後別のキャラクター（例：ベガ）の特設ページを作る際は、このページの構成と `akuma.css` の設計をテンプレート（ベース）として流用すること。
- DBから取得しているフレームデータや技名と、ハードコードされている解説文との間で矛盾が生じないように注意する（パッチが当たった際は両方の確認が必要）。
