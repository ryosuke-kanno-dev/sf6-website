# 豪鬼特設ページ (akuma.php) 仕様設計書

> 実装済み。当初の設計（`sections/akuma/`へのファイル分割）とは異なる形（単一の`akuma.php`ファイル）で
> 実装されているため、本ファイルは実装に合わせて更新しています。セクション構成の内容面は、
> ほぼ当初の設計書どおりに実現できています。

## 1. ページの目的 (Purpose)
SF6における「豪鬼」というキャラクターを使いこなすために必要な情報を、すべて1ページに集約した特化型ページです。

## 2. ターゲットユーザー (Target User)
- 豪鬼をメインキャラクターとして使用しているプレイヤー
- 豪鬼の強み・弱み、セットアップ（起き攻め・詐欺飛び）を深く理解したいプレイヤー

## 3. データソースと管理方法 (Data Source)

- **JSON（`data/akuma_guide.json`）**: 「強み・弱み」「立ち回りの基本」。`content_blocks.php`で構造化JSON（text/list/table）をレンダリング
- **MySQL**:
  - `characters` / `frame`：`getCharacterBySlug($pdo, 'gouki')` で豪鬼の基本情報・フレームデータを取得
  - `akuma_combos`：実戦コンボ集（`purpose='practical'`）／リーサル判断（`practical` と `lethal` の全コンボを対象にダメージで自動判定）。始動技（`frame` の slug+variant）・位置・ヒット状況・ドライブ/SA消費で絞り込み
  - `akuma_matchups`：キャラクター対策の総評・勝ち筋など（相手キャラ28人分）
  - `akuma_punishes`：要注意技と確反（相手の技 × 距離 × 位置 → 使う豪鬼コンボ＋補足）。フレーム判定は技DBから自動
  - `akuma_opponent_actions` / `akuma_oki_setups` / `akuma_oki_options` / `akuma_oki_outcomes`：起き攻め・セットアップのマトリクス表
- **共通ロジック**: コマンドの画像変換には`command_converter.php`を使用（admin側から呼ぶ場合は`CMD_IMG_BASE`定数の上書きが必要）

## 4. 実装構成 (Implementation Structure)

**`sections/akuma/`へのファイル分割は行っていません。** `akuma.php`1ファイルの中に、セクションごとの
レンダリング関数（`renderAkumaComboCard()`、`renderAkumaMatrixBlock()`、`renderAkumaMatchupCard()`等）を
定義し、ページ本体から呼び出す構成です。これは他の全ページと同じ「1ページ＝1ファイル」の方針に合わせたものです。

**5つのタブ構成**（既存の `.tab-navigation` / `.tab-btn` / `.tab-content` を流用。`character.php` と同じ仕組み）：

| タブ | id | セクション |
| :--- | :--- | :--- |
| 立ち回り | `tab-tactics` | 強み・弱み / 立ち回りの基本 |
| コンボ | `tab-combos` | 実戦コンボ集 / リーサル判断 |
| 起き攻め | `tab-oki` | 起き攻め・柔道（マトリクス）/ セットアップ（マトリクス） |
| 対キャラ | `tab-matchups` | キャラクター対策（28キャラ。要注意技と確反は折りたたみ） |
| データ | `tab-data` | フレームデータ |

## 5. UI / 機能の振る舞い (UI / Functional Behavior)

- **専用テーマカラー**: `--akuma-accent`（紫系）というCSSカスタムプロパティを使い、`.akuma-theme`クラスで
  `--accent-color`をスコープ上書きすることで実現。新しいCSSをほぼ増やさず、既存コンポーネント
  （ボタン・バッジ・タブ・アコーディオン等）がそのまま豪鬼テーマ色になる
- **ページ内ナビゲーション**: 他ページと同じ`includes/toc-sidebar.php`（汎用のスクロール追従サイドバー）を使用。
  豪鬼専用の新規サイドバーは作っていない
- **タブ**: 開いた直後は「内容のある最初のタブ」を表示（準備中のタブから始まらないようサーバー側で決定）。
  内容が無いタブのボタンは薄く表示（`.is-empty`）。URLのハッシュ（`#tab-combos` や `#lethal-combos`）でタブ・セクションを
  直接指定でき、左の目次リンクは別タブのセクションでも「タブを開いてからスクロール」する
- **実戦コンボ集**: 始動技・位置・ヒット状況・使えるドライブ/SAで絞り込み、登録順/ダメージ順/ドライブ消費順で並べ替え
  （全件をサーバーで出力し、クライアント側JSで絞り込む）。「位置問わず」のコンボは常に表示
- **リーサル判断**: 相手キャラ（`characters.vitality`）と残り体力%から残り体力を実数で算出し、`damage >= 残り体力` のコンボを
  リーサルとして判定。同じ絞り込み条件内の最大ダメージとリーサル可否をサマリー表示。`hp_threshold_*` は旧仕様で未使用
- **要注意技と確反**: 対キャラの各カード内の折りたたみ。相手の技ごとにまとめ、距離・位置別に豪鬼のコンボと補足を表示。
  始動技の発生が相手のガード時不利を超える行は「⚠ フレーム上は間に合いません」を表示
- **マトリクス表**: 択（行）×相手の行動（列）の表。セルは勝ち/微勝ち/微負け/負けで色分け（緑系/赤系の濃淡）。
  注釈がある場合はセルに下線を付け、ホバーで表示

## 6. 運用・保守の注意点 (Maintenance)

- 今後別キャラクターの特設ページを作る場合、`akuma.php`のテーマ切り替えの仕組み（`--accent-color`の
  スコープ上書き）はそのまま流用できる。ただし`akuma_combos`等のテーブルは豪鬼専用の独立テーブルなので、
  別キャラ用には同様の専用テーブルを新設するか、`character_id`カラムを持たせた汎用テーブルへ作り直すかを
  事前に検討すること
- 管理画面（`admin/akuma-dashboard.php`、`admin/akuma-combos-edit.php`、`admin/akuma-matchup-edit.php`、
  `admin/akuma-oki-edit.php`）からコンテンツを編集できる。`akuma-dashboard.php` は、総評・勝ち筋の登録状況、
  確反の登録数（件数/技数）、要確認（フレーム上間に合わない行・参照切れ）をキャラ別に表示する。JSON（強み弱み・立ち回りの基本）のみ、
  管理画面が無くファイル直接編集が必要
