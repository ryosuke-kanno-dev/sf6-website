# 用語集 (glossary.php) 仕様設計書

## 1. ページの目的 (Purpose)
格闘ゲーム特有の専門用語やSF6固有のシステム用語を、初心者でも分かりやすく解説する辞書としての役割を果たします。他のページ（コンボ集や対策ページ）から分からない単語があった際の参照先として機能します。

## 2. ターゲットユーザー (Target User)
- 格闘ゲーム用語（例：持続、硬直、起き攻め）の意味が分からない初心者
- システム用語（例：パリィ、ドライブラッシュ）の詳細仕様を確認したい中級者

## 3. データソースと管理方法 (Data Source)
- **データ管理**: `data/glossary.json`
- jsonファイルには以下の要素を含むオブジェクトの配列としてデータを格納します：
  - `term`: 用語の表記
  - `kana`: ふりがな（50音順ソート・インデックス用）
  - `slug`: URLハッシュ用（例: `okizeme`）
  - `description`: 用語の解説（HTML/Markdown対応）
  - `category`: カテゴリ（基本、システム、テクニック等）

## 4. コンポーネント構成 (Component Structure)
- `sections/glossary/nav.php`: 50音やカテゴリで絞り込むためのサイドナビゲーション
- `sections/glossary/main.php`: JSONデータを読み込み、50音順（あ行、か行...）にグループ化して表示するメインコンテンツ

## 5. UI / 機能の振る舞い (UI / Functional Behavior)
- **50音順グループ化**: PHP側で `glossary.json` を読み込み、`kana` の頭文字に基づいて自動的に「あ行」「か行」などのグループ分けを行う。
- **アンカーリンク**: 各用語のカードには `id="term-slug"` のようにアンカータグを付与し、別ページから直接特定の用語へ飛べるようにする（例: `glossary.php#drive-rush`）。
- **リアルタイム検索 (将来拡張)**: 今後、JSを用いたインクリメンタルサーチ（文字入力と同時に用語が絞り込まれる機能）を実装予定（`js/glossary.js`）。

## 6. 運用・保守の注意点 (Maintenance)
- 新しい用語を追加する際は、必ず `glossary.json` に追記する。PHPファイルを直接編集する必要はない。
- `slug` は他ページからのリンクに使用されるため、一度設定したら変更しないこと（変更するとリンク切れを起こす）。
