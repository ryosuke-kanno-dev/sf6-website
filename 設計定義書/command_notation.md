# コマンド表記ルール定義書 (Street Fighter 6 Strategy Site)

フレーム表（`frame.command`）、コンボ（`combos.recipe` / `akuma_combos.recipe`）に登録するコマンドの**書き方の統一ルール**です。
変換処理は `includes/functions/command_converter.php`（`convertCommandToIcons()`）。表記チェックは管理画面の「コマンド表記チェック」（`admin/command-check.php`）。

## 1. 基本方針

- **保存する形式は1つ**：テンキー表記（数字＝方向、`LP/MP/HP/LK/MK/HK`＝ボタン）。フレーム表とコンボは同じ記法で書く。
- 複数の表記（矢印、英語略記 qcf/dp など）を**DBに二重に持たない**。見せ方は表示側で切り替える。
  - フレーム表のコマンド列：「アイコン」（初期）／「テンキー表記（文字）」を切り替え可能（選択はブラウザに保存）。
  - 「テンキー表記の見方」の凡例を折りたたみで表示（初心者向け）。
- 他の表示形式（英語略記・日本語名など）が必要になった場合も、保存データは変えずに「表示の変換」として追加する。

## 2. 書き方

| 種類 | 書き方 | 例 |
| :--- | :--- | :--- |
| 方向 | 数字 `1〜9`（テンキーの位置。`5`は使わず、ニュートラルは `N`）。自キャラが右向きのときの方向 | `2`=↓ `6`=→ `236`=↓↘→ `623`=→↓↘ `214`=↓↙← |
| ダッシュ | `66` / `44` | 前ダッシュ・バックステップ |
| ボタン | `LP MP HP LK MK HK`（弱・中・強のパンチ／キック）。強弱を問わない場合は `P` `K` | `236LP` `2MK` |
| 同時押し | `LPLK` `MPMK` `HPHK`、`PP` `KK`（OD技など） | `236PP` `MPMK`（ドライブパリィ） |
| 連続入力 | `~` | `LP~MP` |
| つなぎ | ` -> `（技の区切り）、` > `（派生）、`or`、`+` | `236LP > 214P[J]` |
| 修飾 | `[J]`=ジャスト `[H]`=ホールド `[HJ]`=ハイジャンプ（ヴァイパー。↓入力直後に↑） `[J/H]` `[OD]` `[IM]`=ドライブインパクト `[NR]`=生ラッシュ `[CR]` `[W]`=歩き `[BJ]` `[BS]` `[D]`=ディレイ `[AUTO]` `[360]` `[360360]` `[1〜9]`=溜め方向、`j.`=ジャンプ中、`N`=ニュートラル、`(x1-3)`=繰り返し | `214LP[H]` `j.HP` |
| 条件の文章 | **丸括弧 `( )` の中**に書く。丸括弧の中は文字のまま表示し、チェック対象外。**1段の入れ子**まで書ける | `(ジャンプ中に)LP` `(近距離で)Nor6LPLK` `(体力25%以下で)236236K` `(キルステップ(前方)中に)6P` |
| 並列の区切り | ` / `（前後に半角スペース）。「AまたはB」 | `(シャドウライズ中に)PP / (ODシャドウライズ中に)P` |
| コマンドなし | 空欄（NULL）にする。`-` は書かない | － |
| 注記だけの行 | 丸括弧で囲む（`※` は付けない） | `(スクトゥム中に打撃を受ける)` |

## 3. 書き方のNG例と直し方（「コマンド表記チェック」で「要確認」になるもの）

| NG（要確認） | 理由 | 直し方 |
| :--- | :--- | :--- |
| `214LPホールド` | 丸括弧の外に日本語がある（文字のまま残る） | `214LP[H]`（ホールドは `[H]`。ホールドのアイコンが表示される） |
| `ガード方向+MPMK` | 同上 | `(ガード方向)+MPMK` |
| `-` | コマンドが無いことを記号で書いている | 空欄（NULL）にする |
| `※ODスクトゥム中に打撃を受ける` | 注記が丸括弧の外にある | `(ODスクトゥム中に打撃を受ける)` |
| `[w]`（小文字） | 修飾子は大文字が正式（表示は小文字でも動く） | `[W]` |
| `(d)特殊キャンセル可能な攻撃ヒット中に)66or(Nor)MPMK` | 丸括弧の開閉が合っていない | `(特殊キャンセル可能な攻撃ヒット中に)66or(Nor)MPMK` など、括弧を揃える |
| `弱P` `L` | 日本語・単独の `L` はボタンとして解釈されない | `LP` |
| `2LP→2LP` | 矢印 `→` は区切りとして解釈されない | `2LP > 2LP` または `2LP -> 2LP` |

## 4. 表示

- コンボ：コマンドは1行で表示し、収まらない場合だけ横スクロール。
- フレーム表：コマンド列はアイコン（20px）表示を初期とし、「テンキー表記（文字）」へ切り替え可能。アイコン表示のとき、マウスを乗せると元の表記（ツールチップ）を表示。検索はテンキー表記（文字）で行える。
- ボタンアイコンの色：弱＝水色、中＝黄、強＝赤（`img/command/` の `lp/mp/hp/lk/mk/hk.png`）。

## 5. 修飾子の追加ルール

- キャラ固有の特殊動作などで、新しい修飾子（`[ ]` 形式）が必要になったら、変換処理（`command_converter.php`）にバッジ表示として追加する。
  例：`[HJ]`＝ハイジャンプ（ヴァイパー。ジャスト `[J]` と同じ立ち位置の修飾子で、`623LP[HJ]` のようにコンボ中にも使う）。
- 新しい修飾子は、管理画面の「コマンド表記チェック」の凡例にも追記する。追加前は「要確認」として検出される。
