# SF6 WebSite 仕様設計書

このドキュメントは、`new-sf6-page` ディレクトリ配下で構築されているSF6攻略サイトの全体構造、各ページの役割、データソース、および設計・運用ルールをまとめたものです。

## 1. プロジェクト概要

- **コンセプト**
  - 初心者がマスターを目指し、特定キャラ（豪鬼）を極めるまでの成長を支援するデータ駆動型攻略サイト
- **ターゲット**
  - SF6初学者から中上級プレイヤー
  - 豪鬼メインのプレイヤー
- **技術スタック**
  - PHP（Routing / Controller / Template）
  - MySQL（Frame/Combo Data等の動的データ）
  - JSON（Static Lists/Tutorials等の静的データ）
  - Vanilla CSS / JS

## 2. ディレクトリ・アーキテクチャ

```text
new-sf6-page/
├── public/                    # ドキュメントルート（公開領域）
│   ├── index.php              # フロントコントローラー（すべてのリクエストを処理）
│   ├── css/                   # 共通CSS、ページ固有CSS
│   ├── img/                   # 画像ファイル
│   ├── js/                    # JSファイル
│   └── videos/                # 動画ファイル
├── src/                       # アプリケーションロジック（非公開領域）
│   ├── pages/                 # 各ページコントローラー（home.php, combo.php 等）
│   ├── includes/              # ヘッダー/フッター、DB設定、共通関数群
│   ├── sections/              # ページのHTMLパーツ（ビュー）
│   └── lib/                   # 外部ライブラリ（Parsedown 等）
├── data/                      # 静的JSONデータ群
├── sql/                       # テーブル定義・初期データSQL
├── _archive/                  # 古いファイルの退避場所
└── .htaccess                  # URLの書き換えルール（フロントコントローラーへのルーティング）
```

**【フロントコントローラーパターンの採用】**
セキュリティと保守性の向上のため、ブラウザからアクセス可能なのは `public/` フォルダのみとしています。
すべてのアクセスは `public/index.php`（フロントコントローラー）を経由し、裏側で `src/pages/` 内の各ページロジックを呼び出します。これにより、URLから `.php` を排除し、共通処理（設定の読み込み等）を一元化しています。

## 3. ページ構成と役割

サイトは「入口」「導入」「練習」「対策」「特化ページ」の5つの軸で構成されています。

| ファイル名   | ページ名       | 主な役割                                         | データソース    |
| ------------ | -------------- | ------------------------------------------------ | --------------- |
| index.php    | 攻略トップ     | サイトの玄関口、最新情報と主要コンテンツへの導線 | JSON            |
| guide.php    | ガイド         | 基本設定、操作タイプ、UI解説をまとめた導入ページ | JSON            |
| glossary.php | 用語集         | 格ゲー用語、システム用語の辞書                   | JSON            |
| roadmap.php  | 上達法         | 段位別の目標設定と練習メニューへの誘導           | Markdown / JSON |
| training.php | 練習する       | 動画付きの練習レコード設定集                     | JSON            |
| combo.php    | コンボ集       | 全キャラ対応のコンボ検索・閲覧                   | SQL             |
| matchup.php  | キャラ対策     | 技データに基づいた確定反撃・対策解説             | SQL / JSON      |
| akuma.php    | 豪鬼特設ページ | 豪鬼専用の深い考察、セットアップ解説             | SQL / JSON      |

## 4. 各ページの詳細設計

### 4-1. index.php (攻略トップ)
サイト全体の入口として、「何が見られるか」と「今何が更新されたか」を中心に構成します。
- **実装構成**: `sections/home/` 配下のコンポーネント（`hero.php`, `quick_nav.php`, `features.php` 等）をインクルード。

### 4-2. guide.php (ガイド)
初心者が最初に読むべき導入情報を集約します。
- **実装構成**: `sections/guide/` 配下のコンポーネント（`getting_started.php`, `operation_types.php` 等）をインクルード。

### 4-3. glossary.php (用語集)
格ゲー用語とシステム用語を、あ行からわ行までまとめます。他ページからの参照先としても機能します。
- **データ管理**: `data/glossary.json`

### 4-4. roadmap.php (上達法)
ランク別の上達法を案内するページです。ユーザーの現在地から、次に練習する内容へつなぐ役割を持たせます。
- **データ管理**: Markdownテキスト、JSON連携

### 4-5. training.php (トレモ実践)
トレーニングモードの機能を使った反復練習の紹介ページです。1セクションを1つの練習メニューとして扱います。
- **データ管理**: `data/training_menus.json`

### 4-6. combo.php (コンボ集)
キャラを「使う」ための情報をまとめるページです。
- **実装構成**: 
  - キャラ選択画面は `sections/_shared/char_select.php` を使用。
  - キャラ固有の処理は `sections/combo/char_detail.php` に委譲。
- **データ管理**: MySQL (`characters`, `combos`, `moves` テーブル)

### 4-7. matchup.php (キャラ対策)
キャラと「戦う」ための情報をまとめるページです。立ち回り・連携崩し・確定反撃を見せます。
- **実装構成**: 
  - キャラ選択画面は `combo.php` と同じく `sections/_shared/char_select.php` を共有。
- **データ管理**: MySQL (`matchup_guides`, `frame` テーブル)

### 4-8. akuma.php (豪鬼特設ページ)
豪鬼を使う人向けの特設ページです。他ページのデータを流用しながら、豪鬼専用の思考やセットアップを深掘りします。
- **実装構成**: `sections/akuma/` 配下の各セクションをインクルード。
- **特徴**: フレームデータなどは `matchup.php` 用のDBから自動連携しつつ、豪鬼固有の解説をオーバーライド可能に設計。

## 5. データ管理と共通化方針

ページごとに管理方法を分けることで、更新しやすさを担保します。

| データ種別                 | 管理方法       | 用途                                               |
| -------------------------- | -------------- | -------------------------------------------------- |
| 文章主体の説明             | Markdown / PHP | ガイド、ロードマップ、思想説明                     |
| 一覧系の静的情報           | JSON           | 用語集、チュートリアル、練習項目                   |
| 技やコンボのような検索対象 | MySQL (PDO)    | コマンド、コンボ、技データ、キャラクターマスタ     |

### 5-1. PHP/DBロジックの共通化（DRY原則）
- **DBヘルパー**: キャラクター取得など、複数ページで使うSQL処理は `includes/functions/db_helpers.php` に集約しています。
- **UI共通化**: キャラ選択画面など、同一レイアウトのパーツは `sections/_shared/` に集約し、`$currentPage` 変数を用いて表示を動的に切り替えます。

## 6. 開発・運用ルール（命名規則）

- **ファイル・フォルダ名**: すべてのPHPファイル名は**スネークケース**（例: `getting_started.php`）で統一します。
- **キャラクター名の統一**: URLスラッグ、CSSファイル名、画像フォルダ名等はすべて統一された名称（例: 豪鬼の場合は `akuma`）を使用します。
- **不要ファイルの扱い**: 一時的に不要になったが後で使うかもしれないコード・旧ファイルは、完全に削除せず `_archive/` フォルダへ退避させます。

## 7. デザインガイド

### 7-1. カラーパレット

| 要素               | 推奨色                        | 理由                                               |
| ------------------ | ----------------------------- | -------------------------------------------------- |
| ベース背景         | #121212（深いグレー/黒）      | 目が疲れにくく、文字が浮き立つ                     |
| コンテンツ背景     | #1E1E1E（少し明るいグレー）   | セクションの区切りを明確にする                     |
| メインアクセント   | #FFD700（ゴールド）or #FF4500 | SF6のロゴやドライブゲージを想起させる              |
| サブアクセント     | #00FFFF（シアン）             | モダンなデジタル感を演出                           |
| ポジティブ（有利） | #00FF7F（明るい緑）           | フレーム有利、コンボ成功などを直感的に伝える       |
| ネガティブ（不利） | #FF3E3E（明るい赤）           | 確定反撃、ガード後不利フレームなどを直感的に伝える |

### 7-2. タイポグラフィと見出し

- **H1（ページタイトル）**: 左側に太めのアクセントカラー縦線。背景に薄いグラフィティ風テクスチャ。太めのゴシック体。
- **H2（セクション見出し）**: かすれたブラシ風の下線。濃いグレー背景 + アクセント文字色。
- **コンボ/コマンド表記**: 等幅フォント（Monospace）を使用。コマンドアイコンは専用のCSSクラス（`.c-cmd-img`）を適用し、画像として表示。

### 7-3. レイアウト（モバイルファースト）

- **デスクトップ**: 左サイドバーにグローバルナビゲーション。中央にメインコンテンツ。
- **モバイル**: 下部固定ナビ。長い表（フレームデータなど）はアコーディオン化して初期折りたたみ。
