# 残タスク・追加データ要件一覧

本ドキュメントは、サイトのフロントコントローラー化およびデザインリファクタリングが完了した現状において、「仮データ」としてプレースホルダーが置かれている箇所や、今後「本番データ」として実装・追加が必要になる作業をまとめたものです。

## 1. キャラクター個別ページ（例: `akuma.php`）のDB連携とデータ拡充
現状、`akuma.php` 内で読み込まれる各セクション（`src/sections/akuma/*.php`）は、大部分が**仮データ（静的コンテンツ）**の直書きになっています。

* **対応が必要なファイル**: `src/sections/akuma/` 内の各ファイル
* **残タスク**:
  - [ ] **フレームデータ（技データ）の表示**: 現状「技データは準備中です」となっているため、DB（`frame` テーブルなど）からキャラクターのフレームデータを取得して表形式で出力するロジックの実装。
  - [ ] **動的コンテンツへの移行**: 「リーサル判断」「キャラ対策サマリー」「セットアップ」「起き攻め」「立ち回り」「強み・弱み」がすべて仮データのため、これらを `characters` 関連テーブルや Markdown ファイルからの動的読み込みに改修する。
  - [ ] **汎用化**: 現在は `akuma.php` として独立しているが、将来的に全キャラクターに対応できるよう、`character.php?char=akuma` のようなルーティング・テンプレートの汎用化を検討する。

## 2. コンボページ（`combo.php`）のコマンドリスト実装
* **対応が必要な箇所**: `src/sections/combo/char_detail.php`
* **残タスク**:
  - [ ] **コマンドリストの表示**: 現状「コマンドリストは準備中です」となっている。DBの `movelist` テーブルから対象キャラクターの必殺技・通常技一覧を取得し、一覧として画面にレンダリングする処理の実装。

## 3. キャラ対策ページ（`matchup.php`）の詳細データ投入
* **対応が必要な箇所**: `src/sections/matchup/char_detail.php`
* **残タスク**:
  - [ ] **対策コンテンツの実装**: 一部のコンテンツエリアに `<div class="c-card p-matchup__pending">準備中です。</div>` が存在している。
  - [ ] `matchup_guides` テーブル等に本番データを投入し、特定技への確定反撃や、詳細な立ち回り対策テキストを出力するようにする。

## 4. ガイドページ（`guide.php`）の画像・動画アセット手配
* **対応が必要な箇所**: `src/sections/guide/devices.php`, `src/sections/guide/tutorials.php`
* **残タスク**:
  - [ ] **デバイス画像**: `devices.json` に紐づくコントローラー画像（アケコン、パッド、レバーレス等）が不足しており、「画像準備中」となっている。実際の画像を `public/img/device/` フォルダへ配置する。
  - [ ] **チュートリアル画像/動画**: チュートリアルの解説用メディアが不足しており、「画像準備中」となっている。GIF動画やスクリーンショットを用意し、適切なフォルダへ配置する。

## 5. JSONデータの画像アセット用意
* **対応が必要な箇所**: `data/characters.json`, `data/updates.json`
* **残タスク**:
  - [ ] 各JSONファイル内で定義されている `image`（例: `img/characters/akuma.png` や `img/updates/akuma_update.jpg`）の実体ファイルを用意し、`public/img/` 以下に配置する。

## 6. その他共通項目（フッター等）
* **対応が必要な箇所**: `src/includes/footer.php`
* **残タスク**:
  - [ ] **SNSリンクの設定**: 「※SNSアカウント準備中」となっているため、実際の X (旧Twitter) や YouTube チャンネルなどのURLを発行し、リンクを設定する。

---

## 手軽に終わるタスクからの推奨実行手順（難易度順）

手軽に進められる（コーディング量が少ない、またはアセットの配置のみで終わる）タスクから順に進める場合の推奨ルートです。まずは小さなタスクを完了させて進捗を生み出し、徐々にロジック実装（DB連携等）に進む流れになります。

### 【フェーズ 1：超低難易度・アセット準備】（まずはここから）
1. **SNSリンクの設定（その他共通項目 - タスク6）**
   - **難易度**: ★☆☆☆☆ (非常に簡単)
   - **作業ファイル**: `src/includes/footer.php`
   - **内容**: フッターにある「※SNSアカウント準備中」のテキストを、実際のXやYouTubeなどのURLリンクに書き換えるだけです。
2. **JSONデータの画像アセット用意（タスク5）**
   - **難易度**: ★☆☆☆☆ (画像配置のみ)
   - **作業フォルダ**: `public/img/` 以下の該当パス
   - **内容**: `data/characters.json` や `data/updates.json` で定義されている画像パス（例: `img/characters/akuma.png` など）に、実体画像ファイルを配置します（コードの修正は不要です）。
3. **ガイドページの画像・動画アセット手配（タスク4）**
   - **難易度**: ★★☆☆☆ (画像・動画の準備)
   - **作業フォルダ**: `public/img/device/` などのアセットフォルダ
   - **内容**: デバイス紹介用の画像（アケコンやパッド等）や、チュートリアル用のGIF動画・スクショを所定のフォルダへ配置します。

### 【フェーズ 2：中難易度・限定的なDB連携】（部分的なロジック実装）
4. **コンボページのコマンドリスト実装（タスク2）**
   - **難易度**: ★★★☆☆ (中程度・PHPとSQL)
   - **作業ファイル**: `src/sections/combo/char_detail.php`
   - **内容**: DBの `movelist` テーブルからキャラクターの技一覧を取得し、画面にレンダリングするPHPロジックを追加します。

### 【フェーズ 3：高難易度・大規模なDB連携と設計変更】（本格的なシステム構築）
5. **キャラ対策ページの詳細データ投入（タスク3）**
   - **難易度**: ★★★★☆ (やや難しい・DB構築とUI連携)
   - **作業ファイル**: `src/sections/matchup/char_detail.php`
   - **内容**: `matchup_guides` テーブルのデータ構造を整備し、対戦相手ごとの確定反撃や対策テキストを動的に表示する処理を実装します。
6. **キャラクター個別ページのDB連携とデータ拡充・汎用化（タスク1）**
   - **難易度**: ★★★★★ (最も難しい・全体設計に関わる)
   - **作業ファイル**: `src/sections/akuma/` 内の各ファイル、ルーティングテンプレート
   - **内容**:
     - `frame` テーブルからフレームデータを取得し、技データテーブルとして出力。
     - 「リーサル判断」「立ち回り」などの仮データをDB/Markdownから動的取得する形にリファクタリング。
     - `akuma.php` 固有の処理から、`character.php?char=akuma` のように全キャラ対応可能な汎用テンプレートシステムへとルーティングを移行。

---

**今後の進め方（おすすめ）**
- **手軽さ重視で進める場合**: 上記の **【フェーズ 1】** から順に進めることで、短時間で「準備中」の表示を減らすことができます。
- **システム完成度重視で進める場合**: **【フェーズ 2】** のコンボページや、**【フェーズ 3】** のキャラクター個別ページ汎用化から進めることで、Webアプリケーションとしての主要な機能の骨組みが完成します。
