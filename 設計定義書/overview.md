# SF6攻略サイト — プロジェクト紹介

> 「初心者がマスターを目指し、豪鬼を極めるまでの成長を支援するデータ駆動型のストリートファイター6攻略サイト」

---

## このプロジェクトについて

ストリートファイター6（SF6）は、カプコンが2023年にリリースした対戦格闘ゲームです。  
このサイトは、SF6を「なんとなく遊んでいる状態」から「ランクを上げて楽しめる状態」へ最短で到達するための、実践的な攻略情報を提供することを目的に作られました。

「コンボを覚えたいが、何から手をつければいいか分からない」  
「キャラ対策の情報がバラバラで探しにくい」  
「トレーニングモードで何を練習すればいいか分からない」

そういった悩みを、このサイト1つで解決することを目指しています。

---

## サイトで提供できるもの

| コンテンツ | 内容 |
| --- | --- |
| 🎮 スタートガイド | デバイス選び・操作タイプ・ゲーム設定など初心者向け導入情報 |
| 📈 上達ロードマップ | ランク帯（ゴールド〜マスター）ごとに「次にやるべきこと」を提示 |
| 🎯 トレモ実践メニュー | 具体的なレコード設定と実践動画付きの練習メニュー |
| 📚 コンボ集 | 全キャラクター対応のコンボデータベース。難易度・状況別に絞り込み可能 |
| ⚔️ キャラ対策 | 相手キャラの技データ・確定反撃・立ち回りのセオリーをまとめた対策集 |
| 🔥 豪鬼特設ページ | 豪鬼専用の思考法・セットアップ・コンボ・フレームデータを深掘り |
| 📖 用語集 | 格闘ゲーム用語・SF6システム用語の辞書（あ行〜わ行） |

---

## 技術的なポイント（エンジニア向け）

- **言語**: PHP / MySQL / Vanilla CSS / JavaScript
- **設計**: コントローラー（`.php`）とビュー（`sections/`）を分離したコンポーネント指向
- **データ管理**: 動的データ（コンボ・フレームデータ）はMySQL、静的データ（用語集・練習メニュー）はJSON
- **コマンドアイコン変換**: `command_converter.php` により「236HP」などのコマンド文字列をゲーム内の方向キー・ボタン画像に自動変換

---

## 開発の背景・こだわり

単なる情報まとめサイトではなく、「読んだらすぐに実践できる」設計にこだわっています。

- 上達ロードマップからトレモメニューへ自然に誘導
- コンボ集はキャラ選択→コンボ確認が2クリックで完結
- キャラ対策ページはフレームデータ（DB）と解説テキストが連動
